# SI2_P2

El objetivo de esta práctica es implementar un mecanismo de comunicación entre
aplicaciones clientes y servidores, utilizando diversas soluciones ampliamente emplea-
das en la industria, tales como:

* **RPC (Remote Procedure Call)**: un protocolo que permite invocar procedi-
mientos remotos como si fueran locales, con transparencia de datos, ofreciendo
mayor integración y menor sobrecarga en ciertos casos.
* **Sistemas de colas de mensajes**: que introducen una capa de asincronía y
desacoplamiento entre los componentes, favoreciendo la tolerancia a fallos y la
escalabilidad.
